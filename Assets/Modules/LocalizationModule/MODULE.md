# Localization

## Purpose
Translates every player-facing text: holds the string tables per language, the chosen language, and announces when it changes.

## Concepts
localization, language, translation, Turkish, English, string table, ILocalizationService, CD_Localization

## Decisions
- A row's Key is the English text itself; Turkish is a column and English is filled only where the shown English
  differs from the key. Code calls `Get(key)` or `Format(key, args)` with the English literal, so a missing row
  falls back to readable English instead of a key name.
- CD_Localization.FillDefaults is the source of the shipped rows and the asset is kept in step with it; a new
  player-facing string gets its row in both.
- Other modules translate at the point they build a string (a Command, a Function), never in a View, except the
  fixed labels of a screen, which the screen registers and retranslates when the language changes.
