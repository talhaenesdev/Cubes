# GameplayScreenModule

## Purpose
The screen a run is played on, opened when the player presses Play.

## Concepts
gameplay screen, run, HUD

## Presentation contract
The NIGHT SHIFT HUD builds its UI once in Awake under the ScreenManager-owned screen,
using LegacyRuntime.ttf and flat UI graphics. It creates no canvas or texture assets.
RefreshHud(status, objective) displays both strings verbatim while shown; gameplay owns
all mission, death and pause wording. Send a fresh update after each opening: pooled
screens unsubscribe and reset their old text before activation. RetryRequested and
MenuRequested announce button presses; their consequences belong to gameplay wiring.
Buttons bind on enable/disable and the mediator binds on show/hide completion.
